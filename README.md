# Kommandekollen

Bostadsbevakning av kommande bostader i Stockholm.

Projektet ar under utveckling och ar inte publicerat.

## Bekraftade forutsattningar

- Doman: `kommandekollen.se`, kopt av agaren.
- Avsett GitHub-konto: `marcusbodin`, inte `marbodin`, Microsoft eller Mojang.
- Agaren har godkant ett publikt kodrepo for kostnadsfri GitHub Pages.
- Frontend pa GitHub Pages; backend pa Cloudflare Workers/D1; mejl via Resend.
- Endast gratisnivaer for driften. Ingen automatisk uppgradering till betalplan.
- Oppen tjanst med separata sokpreferenser och mejlverifiering.
- Prenumeranters uppgifter och hemligheter far aldrig lagras i repot.

## Datakallor

Automatisk hamtning maste granskas per kalla. Att robots.txt tillater en URL
innebar inte i sig ett tillstand att aterpublicera innehall.
Full tackning av Stockholms maklare ar ett mal, inte en befintlig funktion.

Fastighetsbyrans robots.txt anger uttryckligen att automatisk hamtning kraver
sarskilt tillstand. Den kallan ska vara avstangd utan sadant tillstand.

## Publicering

Publicering ar blockerad tills GitHub ar anslutet som `marcusbodin` och
Cloudflare, Resend och domanens DNS har konfigurerats av agaren.
Inga konton, DNS-poster eller driftsresurser har skapats av detta projekt.
